              Intuitive Analogy: Query, Key, and Value ($Q, K, V$)
            

            

              

                
Query ($Q$)

                

                  What the current token is looking for. Represents an information request sent to all tokens in the context.
                

              

              

                
Key ($K$)

                

                  What information each token offers. The dot product $Q \cdot K^T$ calculates how well the Query matches the Key.
                

              

              

                
Value ($V$)

                

                  The actual semantic content extracted and blended together in proportion to the calculated attention weights.

 AI Curriculum

            
Foundational Concepts & Theory

            

              Explore the mathematical underpinnings, algorithmic breakthroughs, and intuitive explanations behind modern Large Language Models and Transformers.
            

          


          
          

            

              

                
                1. What is a Large Language Model (LLM)?
              

              
            

            

              A Large Language Model is fundamentally a next-token probability estimator trained on vast textual datasets. Given an arbitrary sequence of tokens $x_1, x_2, \dots, x_t$, the model learns parameters $\theta$ to optimize:
              

                P(x_{t+1} \mid x_1, x_2, \dots, x_t; \theta)
              

              By learning to predict the next token with high fidelity across billions of web documents, books, and code repositories, the network implicitly develops complex internal representations of syntax, reasoning, semantics, and world knowledge.
            

          


          

            

              

                
                2. Why Tokenization & Byte Pair Encoding (BPE)?
              

              
            

            

              Computers cannot natively read characters or words as strings. We could split text by words (word-level), but that creates an infinitely growing vocabulary with Out-Of-Vocabulary (OOV) errors for new words. We could also split by characters (character-level), but that causes sequences to become extremely long, requiring immense compute.
              


              Byte Pair Encoding (BPE) offers the optimal compromise:
              
    
                
  • Frequent full words remain single whole tokens (e.g., "the", " cat").
    • 
                
  • Rare or unknown words are decomposed into familiar subword pieces (e.g., "un" + "friend" + "liness").
    • 
                
  • Arbitrary Unicode bytes ensure zero OOV errors while maintaining compact sequence lengths.
    • 
              

            

          


          

            

              

                
                3. High-Dimensional Vector Embeddings & Vector Space
              

              
            

            

              Once tokenized into discrete integer IDs ($[42, 1083, 7]$), each ID is looked up in a continuous embedding table $W_E \in \mathbb{R}^{V \times d_{model}}$.
              

                \mathbf{e}_i = \text{EmbeddingLookup}(\text{TokenID}_i)
              

              In this continuous $d$-dimensional space (e.g. $d=4096$ in LLaMA-3), geometrical proximity corresponds to semantic proximity:
              
    
                
  • Words with similar meanings cluster together (e.g., dog and puppy).
    • 
                
  • Directions encode conceptual relationships: $\mathbf{v}_{\text{King}} - \mathbf{v}_{\text{Man}} + \mathbf{v}_{\text{Woman}} \approx \mathbf{v}_{\text{Queen}}$.
    • 
              

            

          


          

            

              

                
                4. Scaled Dot-Product Self-Attention
              

              
            

            

              Introduced in the seminal paper "Attention Is All You Need" (Vaswani et al., 2017), the self-attention formula is:
              

                \text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
              

              Where:
              
    
                
  • $\mathbf{Q} = \mathbf{X} W_Q$: Queries (what each token is searching for).
    • 
                
  • $\mathbf{K} = \mathbf{X} W_K$: Keys (what each token advertises).
    • 
                
  • $\mathbf{V} = \mathbf{X} W_V$: Values (the contextual payload).
    • 
                
  • $\sqrt{d_k}$: Scaling factor preventing dot-product magnitudes from exploding into saturation regions of the softmax function.
    • 
              

            

          


          

            

              

                
                5. Cosine Similarity vs. Euclidean Distance
              

              
            

            

              When measuring vector similarity in high dimensions:
              
    
                
  • Euclidean Distance ($\|\mathbf{u} - \mathbf{v}\|_2$) is sensitive to vector magnitude (document length or word frequency can artificially increase distance).
    • 
                
  • Cosine Similarity ($\frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2}$) evaluates the angle between vectors, ignoring length. It ranges from $-1$ to $+1$, making it standard across vector databases and retrieval-augmented generation (RAG).
    •
